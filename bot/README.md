# 🤖 ربات مدیریت امتیاز کانال — Telegram Points Bot (فارسی)

ربات تلگرام برای مدیریت و محاسبه‌ی امتیاز اعضای کانال/گروه شما:

- 📒 **اطلاعات اعضا**: نام، سن، یوزرنیم و آیدی عددی هر عضو (SQLite)
- ⚠️ **اخطار** (۱-)، 🔴 **استرایک** (۳-) و 🟢 **امتیاز مثبت** (۱+) توسط ادمین‌ها
- 🧮 **قانون پاک‌سازی**: هر ۵ امتیاز مثبت = پاک‌کردن ۱ استرایک، هر ۳ = پاک‌کردن ۱ اخطار
- ⚖️ **دادگاه استرایک**: با دستور استرایک، رأی‌گیری خودکار باز می‌شود؛ اعضا (به‌جز خودِ فرد) می‌دهند و رأی بیشتر برای استرایک یا فرصت دیگر تصمیم می‌گیرد — مساوی → «آخرین فرصت تغییر نظر»، مساوی دوباره → استرایک قطعی
- 📈 **آمار اعضا**: IQ، COMEDY، SIMPNESS و RETARDNESS برای هر عضو (۰ تا ۱۰۰، نوار متنی) — تغییر فقط با رأی‌گیری و اکثریت بیش از ۵۰٪ تایید
- 🌟 **توانایی شخصی**: هر عضو یک توانایی خودنوشته دارد؛ همیشه خط اول آمار و با نوار ۱۰۰٪ نمایش داده می‌شود
- 🏆 **رتبه‌بندی دوگانه**: /ranking برای جدول امتیازها و /ranking stats برای رتبه‌بندی بر اساس میانگین آمار — همراه مدال برای ۳ نفر برتر و نمایش رتبه‌ی خودتان
- 🔨 **مجازات خودکار استرایک**: رسیدن به ۳ استرایک باقی‌مانده = میوت ۱ روزه، به ۵ = اخراج از گروه
- 📊 گزارش نهایی هر عضو با جزئیات کامل محاسبه + گزارش کل اعضا
- 🗣 کاملاً **فارسی** (با ارقام و تاریخ شمسی)
- ⚙️ تغییر زنده‌ی کلمات دستورات (اخطار / استرایک / امتیاز) داخل خودِ ربات

## ۱) ساخت ربات از BotFather (شما فقط این بخش را انجام می‌دهید)

1. در تلگرام [`@BotFather`](https://t.me/BotFather) را باز کنید (تیک آبی را چک کنید)
2. `/newbot` را بفرستید
3. یک **نام نمایشی** انتخاب کنید (مثلاً «ربات امتیاز کانال»)
4. یک **یوزرنیم** انتخاب کنید که به `bot` ختم شود و تکراری نباشد (مثلاً `MyChannelPointsBot`)
5. توکن را کپی کنید (شبیه `123456789:AAxxxx…`) — **آن را به کسی ندهید**
6. ربات را به کانال/گروه خود اضافه کنید و **ادمین**اش کنید
7. دستور `/setprivacy` → انتخاب بات → **Disable** (بدون این، ربات «اخطار» و «استرایک» را نمی‌بیند؛ مگر اینکه ادمین باشد)

### (اختیاری) تنظیم منوی دستورات در BotFather

`/setcommands` را بفرستید، بات را انتخاب کنید و این متن را بفرستید:

```
start - شروع
help - راهنما
menu - پنل مدیریتی
mypoints - امتیاز من
points - گزارش امتیاز یک کاربر
addmember - ثبت عضو جدید
report - گزارش همه‌ی اعضا
words - نمایش کلمه‌های دستورات
```

## ۲) نصب

```bash
# روی سیستم لوکال یا VPS
git clone <repo-url> telegram-bot   # یا فایل‌ها را با scp/rsync منتقل کنید
cd telegram-bot

python3 -m venv .venv
source .venv/bin/activate          # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env               # ویندوز: copy .env.example .env
```

بعد `.env` را باز کنید و پر کنید:

```env
BOT_TOKEN=123456789:ExActualTokenFromBotFather
MASTER_ADMIN_IDS=123456789        # آیدی عددی خودتان؛ چند تا: با کاما
MASTER_ADMIN_USERNAMES=kouroshhsam
```

> آیدی عددی خودتان را بعد از اجرا با `/id` در چت با ربات بگیرید و در `.env` بگذارید.

اجرا:

```bash
python bot.py
```

## ۳) استقرار روی VPS (Ubuntu/Debian)

```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip
# پروژه را به /home/USER/telegram-bot منتقل کنید و مراحل نصب بالا را انجام دهید

sudo cp telegram-bot.service /etc/systemd/system/telegram-bot.service
sudo nano /etc/systemd/system/telegram-bot.service   # مسیرها و یوزر را اصلاح کنید
sudo systemctl daemon-reload
sudo systemctl enable --now telegram-bot
journalctl -u telegram-bot -f                          # مشاهده‌ی لاگ‌ها
```

پورت ورودی لازم نیست؛ ربات با **polling** و فقط خروجی اینترنت کار می‌کند.

### نصب با Docker (اختیاری، ساده‌تر)

```bash
docker build -t telegram-strike-bot .
docker run -d --name strike-bot --restart unless-stopped \
  --env-file .env -v strike-bot-data:/data \
  telegram-strike-bot
```

دیتابیس در volume ثابت **strike-bot-data** ذخیره می‌شود و با ری‌استارت/آپدیت از بین نمی‌رود.

### بک‌آپ خودکار روزانه

```bash
# روی VPS (cron): ۰ ۳ بامداد هر روز
crontab -e  →  0 3 * * * /home/USER/telegram-bot/backup.sh
```

روی ویندوز یک‌بار `backup.bat` را اجرا کنید یا آن را در Task Scheduler زمان‌بندی کنید.
بک‌آپ‌ها در `backups/` ذخیره می‌شوند و لیست `.gitignore` هستند.

## ۴) دستورات ربات

### ثبت امتیاز (فقط ادمین‌های کانال یا ادمین‌های اصلی)

روش ریپلای (پیشنهادی): روی پیام شخص **ریپلای** کنید و یکی از کلمه‌ها را بنویسید:

| کلمه پیش‌فرض | عملکرد | معادل لاتین |
|---|---|---|
| `اخطار` | ۱ امتیاز منفی | `/warn` |
| `استرایک` | تشکیل دادگاه استرایک با رأی‌گیری گروه | `/strike` |
| `امتیاز` | ۱ امتیاز مثبت | `/plus` |

مثال: `اخطار بدگویی در چت` یا `امتیاز همکاری عالی`

روش بدون ریپلای:

```
اخطار @username دلیل تخلف
استرایک 123456789 توهین
امتیاز @username همکاری خوب
/warn @username دلیل
```

> نکته: `@username` فقط وقتی کار می‌کند که کاربر قبلاً در دیتابیس ثبت شده باشد؛ وگرنه از **آیدی عددی** یا **ریپلای** استفاده کنید.

### مشاهده‌ی گزارش (ادمین‌ها)

| دستور | عملکرد |
|---|---|
| `/points` | گزارش کامل یک کاربر (ریپلای یا آیدی/یوزرنیم) |
| `/mypoints` | امتیاز خودتان (برای همه) |
| `/report` | جدول نهایی همه‌ی اعضا |
| `/history` | ۱۰ رویداد آخر یک کاربر |
| `/justice` | تاریخچه‌ی آخرین ۱۰ دادگاه (با یوزرنیم/ریپلای برای یک نفر خاص) |
| `/stats` | آمار خودتان یا یک نفر دیگر (بارهای ۰ تا ۱۰۰) |
| `/mystats` | آمار خودتان |
| `/allstats` | آمار کلی همه‌ی اعضای ثبت‌نام‌شده (ادمین‌ها) |
| `/ranking` | جدول رتبه‌بندی امتیاز (با مدال برای ۳ نفر برتر + رتبه‌ی خودتان) |
| `/ranking stats` یا `/statsranking` | رتبه‌بندی اعضا بر اساس میانگین آمار (💡+😂+🥰+🐢) |

## ۵‌ـ۴) 📈 آمار اعضا (۰ تا ۱۰۰)

هر عضو ثبت‌نام‌شده چهار آمار ۰ تا ۱۰۰ دارد: 💡 IQ، 😂 COMEDY، 🥰 SIMPNESS، 🐢 RETARDNESS — نمایش به شکل نوار متنی، مثل `████████░░ ۸۰٪`. هر آمار در یک خط جدا نمایش داده می‌شود.

```
/stats                ← آمار خودتان
/stats @ali           ← آمار یک نفر
/stat iq @ali         ← پیشنهاد افزایش ۵٪ (رأی‌گیری گروه)
/stat iq @ali take    ← پیشنهاد برگرداندن ۵٪ (رأی‌گیری گروه)
```

آمار فقط با **رأی‌گیری** تغییر می‌کند: ✅ تایید | ❌ رد؛ بیش از **۵۰٪ تایید** لازم است (مساوی = بدون تغییر)؛ خودِ فرد نمی‌تواند رأی دهد؛ رأی قابل تغییر است تا بسته شدن؛ رأی‌گیری ۵ دقیقه باز است و ادمین‌ها با «🏁 اعلام نتیجه» زودتر می‌بندند. از پنل شروع (/start) دکمه‌ی **📈 آمار اعضا** آمار کلی همه را نشان می‌دهد. رأی‌گیری در جداول `stat_proposals` و `stat_votes` ذخیره می‌شود.

## ۵‌ـ۵) 🌟 توانایی شخصی (خط اول آمار)

هر عضو می‌تواند **یک توانایی شخصی** برای خودش تعریف کند (ویرایش‌پذیر، هر وقت خواست):

```
/ability سریع مثل صاعقه
```
یا از داخل `/stats` روی دکمه‌ی «🌟 تنظیم توانایی شخصی» بزنید و متن را بفرستید.

توانایی به‌عنوان **خط اول آمار** شما نمایش داده می‌شود و همیشه **۱۰۰٪** است، مثل این‌ها:
```
📊 آمار «علی»
🌟 توانایی: «کارتر خشم‌آلود»  ██████████  ۱۰۰٪
💡 IQ ...
```
در فهرست «📈 آمار کلی اعضا» هم، برای هر عضو توانایی‌اش اولین خط قبل از سایر آمارها نمایش داده می‌شود.

مثال خروجی گزارش:

```
📊 گزارش امتیازها — «علی احمدی»
🆔 آیدی: ۱۲۳۴۵۶۷۸۹
🔗 یوزرنیم: @ali
🎂 سن: ۲۵ سال

🟡 اخطار: ۲ بار  →  ۲- منفی
🔴 استرایک: ۱ بار  →  ۳- منفی
🟢 امتیاز مثبت: ۷ بار  →  ۷+ مثبت

➖ پاک‌شده: ۱ استرایک (هر ۵ پلاس) + ۰ اخطار (هر ۳ پلاس)
🧮 مثبت: +۷  |  منفی باقی‌مانده: -۲

🏁 امتیاز نهایی: +۴ ✅
```

### مدیریت اعضا (فقط ادمین‌ها)

```
/addmember 123456789 علی رضایی 25     ← آیدی + نام + سن
/addmember علی رضایی 25               ← ریپلای به پیام کاربر
/addmember                             ← فرم مرحله‌به‌مرحله (پرسش نام و سن)
/member                                ← کارت یک عضو
/listmembers                           ← لیست صفحه‌بندی‌شده اعضا
/setname @ali علی رضایی ثانی           ← تغییر نام
/setage @ali 26                        ← تغییر سن
/delmember @ali                        ← حذف عضو (تاریخچه حفظ می‌شود)
```

### تغییر کلمه‌های دستورات (فقط ادمین اصلی)

```
/words                          ← نمایش کلمه‌های فعلی
/setword warn حمله              ← کلمه‌ی اخطار را «حمله» کنید
/setword strike خطا             ← کلمه‌ی استرایک را «خطا» کنید
/setword plus تشویق             ← کلمه‌ی امتیاز را «تشویق» کنید
```

تغییرات بلافاصله و بدون نیاز به ری‌استارت اعمال می‌شوند.

### سایر

```

/start   ← شروع و نمایش آیدی شما
/help    ← راهنمای کامل فارسی
/menu    ← پنل دکمه‌ای مدیریت
/cancel  ← لغو فرم جاری
```

## ۵) نحوه‌ی محاسبه (فرمول دقیق)

```
اخطار = ۱-     استرایک = ۳-     امتیاز مثبت = ۱+

منفی کل   = (تعداد اخطار × ۱) + (تعداد استرایک × ۳)
مثبت کل   = تعداد امتیاز مثبت

پاک‌سازی (اول به اولویتی):
  استرایک‌های پاک‌شده = min(استرایک‌ها, مثبت کل ÷ ۵)   ← هر ۵ پلاس = ۱ استرایک
  باقی‌مانده پلاس     = مثبت کل − (استرایک‌های پاک‌شده × ۵)
  اخطارهای پاک‌شده    = min(اخطارها, باقی‌مانده پلاس ÷ ۳) ← هر ۳ پلاس = ۱ اخطار

منفی باقی‌مانده = (استرایک‌های باقی‌مانده × ۳) + (اخطارهای باقی‌مانده × ۱)
نهایی           = مثبت کل − منفی باقی‌مانده

استرایک باقی‌مانده = استرایک‌ها − (مثبت کل ÷ ۵)
```

مثال: ۲ استرایک + ۱ اخطار + ۱۲ پلاس → پاک‌شده: ۲ استرایک (۱۰ پلاس) + ۰ اخطار (۲ پلاس باقی) → منفی باقی‌مانده = ۱ → نهایی = **۱۱+**

## ۵‌ـ۳) ⚖️ دادگاه استرایک (رأی‌گیری خودکار)

با دستور استرایک (ریپلای یا یوزرنیم/آیدی) به‌جای ثبت فوری، یک رأی‌گیری عمومی در گروه باز می‌شود:

- همه‌ی اعضا به‌جز خودِ فرد رأی می‌دهند: **🟥 استرایک بزنید** | **🟩 یک فرصت دیگر**
- رأی‌گیری **۵ دقیقه** باز است؛ ادمین‌ها با دکمه‌ی «🏁 اعلام نتیجه» زودتر می‌بندند
- هر عضو **یک رأی** دارد که تا بسته شدن رأی‌گیری می‌تواند تغییرش دهد
- مساوی شدن اول → «🚨 آخرین فرصت تغییر نظر» (**۲ دقیقه‌ی دیگر**)؛ مساویِ دوباره → **استرایک قطعاً ثبت می‌شود**
- استرایک ثبت‌شده وارد محاسبات امتیاز و مجازات (۳ میوت / ۵ اخراج) می‌شود
- فقط یک دادگاه باز برای هر فرد در هر گروه هم‌زمان مجاز است
- دادگاه‌های باز با ری‌استارت ربات از دست نمی‌روند (بازیابی خودکار در استارت)
- رأی‌گیری در دو جدول `judgments` و `judgment_votes` ذخیره می‌شود (تاریخچه)
- بازنده‌ی دادگاه (رأی مخالف استرایک) = بدون ثبت استرایک، اما ردپایی در رأی‌گیری باقی می‌ماند

## ۵‌ـ۲) مجازات خودکار استرایک

هنگام ثبت یک استرایک، استرایک‌های **باقی‌مانده** چک می‌شود:

| استرایک باقی‌مانده | مجازات |
|---|---|
| ۱ و ۲ | فقط ثبت، بدون مجازات |
| ۳ (و ۴) | میوت ۱ روزه (می‌شود دوباره بعد از پاک‌سازی آزاد شد) |
| ۵+ | اخراج از گروه |

نکته‌ها: مجازات فقط در گروه/سوپرگروه اعمال می‌شود؛ در کانال (چون قابلیت میوت ندارد) فقط پیام هشدار ثبت می‌شود. ادمین‌ها و خود ربات هرگز مجازات نمی‌شوند. برای میوت/اخراج، ربات باید در گروه **ادمین با اجازه‌ی BAN/RESTRICT** باشد.

## ۶) نکات و عیب‌یابی

- **ربات «اخطار» را نمی‌بیند؟** در BotFather → `/setprivacy` → Disable بزنید؛ یا ربات را ادمین کنید.
- **کانال**: ربات باید **ادمین کانال** باشد تا پست‌های کانال را دریافت کند. در کانال‌ها، ادمین‌های ناشناس هم پشتیبانی می‌شوند (پیام از طرف خود کانال ثبت می‌شود).
- **یوزرنیم کار نمی‌کند؟** ربات‌ها نمی‌توانند یوزرنیم ناشناس را به آیدی تبدیل کنند؛ کاربر را یک‌بار با `/addmember` ثبت کنید.
- **پشتیبان‌گیری**: فقط فایل `bot_data.db` (و `bot_data.db-wal`) را کپی کنید؛ همه‌چیز همان‌جاست.
- **امنیت**: توکن را هرگز جایی پست نکنید؛ اگر لو رفت فوراً `/revoke` کنید. فایل `.env` در `.gitignore` است.
- **تاریخچه**: حتی بعد از حذف عضو، رویدادها در جدول `points` باقی می‌مانند.

## English (brief)

Persian-first Telegram bot to track channel/group member points: warnings (−1), strikes (−3), plus points (+1). Erasing: each 5 plus points erase 1 strike; each 3 remaining plus erase 1 warn. Reaching 3 unerased strikes auto-mutes for 1 day; 5 unerased strikes auto-bans. Strikes are not logged directly: issuing a strike opens an automatic public vote (everyone except the victim votes: 🟥 give strike / 🟩 give another chance), open for 5 minutes or until an admin force-closes it; a draw triggers a 2-minute "last chance to change your mind" round, and a second draw means the strike is applied anyway. Members can self-register with `/join` (stores their real Telegram ID + username). Trigger words (Persian defaults `اخطار`, `استرایک`, `امتیاز`) can be changed live by the master admin via `/setword`. Data lives in SQLite (`bot_data.db`). Run: `pip install -r requirements.txt`, fill `.env`, `python bot.py`. On a VPS use the included `telegram-bot.service` systemd unit. Disable privacy mode in BotFather (`/setprivacy` → Disable) or make the bot an admin so it sees the trigger words.
