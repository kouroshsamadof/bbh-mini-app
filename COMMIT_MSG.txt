Fix buttons unresponsive on slow networks

Event listeners were wired after the async refreshState() call, so any
network/tunnel hiccup caused init() to reject silently and none of the
buttons (nav, sign-up, ability save, tabs) ever attached. Now bindEvents()
runs before the data fetch – buttons work even if the API is down.
Added safeRenderAll() fallback so rendering errors still leave a working UI.
