# AZIZ MINI — پنل برادری BBH (تلگرام Mini App)

یک اپلیکیشن مجازیِ کنستراکتوریِ فارسی داخل تلگرام — همه‌ی قابلیت‌های ربات اصلی
(امتیاز، آمار، رتبه‌بندی، دادگاه رأی‌گیری، اعضا، توانایی شخصی) بدون تایپ، با دکمه‌ها.

> ⚠️ **دیتای این‌جا نمایشی/ساختگی است** — هیچ عضو واقعی یا داده‌ی زنده‌ی کانال وارد این اپ نشده.
> برای اتصال به دیتابیس زنده باید روی VPS شما API اجرا شود (می‌تواند مرحله‌ی بعد باشد).

## باز کردن در تلگرام

از منوی ربات **@miniazizbot** دکمه‌ی «پنل BBH» را بزنید (با BotFather تنظیم شده)، یا لینک مستقیم:

https://kouroshsamadof.github.io/bbh-mini-app/

## قابلیت‌ها

- 🏠 **خانه** — داشبورد امتیاز نهایی، رتبه‌ی شما، پیش‌نمایش آمار
- 📊 **آمار** — نوارهای 0 تا 100 (IQ/COMEDY/SIMPNESS/RETARDNESS) + **توانایی شخصی** خودتان (خط اول آمار، همیشه ۱۰۰٪)
- 🏆 **رتبه‌بندی** — دو جدول جدا: امتیاز و میانگین آمار، با کسب مدال برای ۳ نفر برتر
- ⚖️ **دادگاه** — پرونده‌های باز با رأی‌گیری دکمه‌ای (🟥 استرایک / 🟩 یک فرصت دیگر) + تاریخچه‌ی دادگاه‌ها
- 👥 **اعضا** — فهرست اعضا با امتیاز نهایی آن‌ها مرتب‌شده
- نوار آمار متحرک، تم تیره/روشن خودکار تلگرام، بازخورد لمسی (Haptic)
- کاملاً فارسی و راست‌چین (RTL)

## ساختار

```
index.html     ← اسکلت اپ (سربرگ، صفحات، نوار پایین)
css/style.css  ← تم تلگرام (تم تیره/روشن با متغیرهای CSS تلگرام)
js/app.js      ← داده‌ی نمایشی + منطق رندر + رأی‌گیری و توانایی (localStorage)
```

## آپدیت و انتشار

این مخزن روی گیت‌هاب پابلیک است و با **GitHub Pages** سرو می‌شود. هر
`git push` روی شاخه‌ی `main` به صورت خودکار سایت را به‌روزرسانی می‌کند.

## برای توسعه

هر تغییری در `js/app.js` را با `node --check js/app.js` بررسی کن، و قبل از push
از بودن DOM IDها مطمئن شو (`id=`های رفرنس‌شده در JS باید در HTML باشند).
